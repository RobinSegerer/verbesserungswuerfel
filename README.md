# Verbesserungswürfel

Eine kleine, statische Web-App mit 24 positiven Tagesmissionen in vier Bereichen:

- Gesundheit
- Altruismus
- Bildung
- Umwelt

Die App funktioniert vollständig im Browser, ohne Framework, Backend oder externe Abhängigkeiten.

## GitHub Pages

In diesem Repository unter **Settings → Pages** als Quelle **Deploy from a branch** auswählen und anschließend **main / (root)** veröffentlichen.

Danach ist die App unter `https://robinsegerer.github.io/verbesserungswuerfel/` erreichbar.
